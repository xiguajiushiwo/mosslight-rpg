# Journey expansion integration contract

New playable entry: journey.html. Preserve the original index.html experience and v2 saves; link new campaign from index.html. New modules are UMD globals and CommonJS exports. Runtime has no third party dependencies.

## Data: src/journey-data.js → MosslightJourneyData

Export `{CHAPTERS, SIDEQUESTS, CAST, ITEMS, WEAPONS, RECIPES, BUILDINGS}`.
CAST maps speaker IDs to `{name,role,portrait}` where portrait uses existing hero/father/mother/suwan/narrator/merchant. Include hero,father,mother,suwan,brother,doctor,scribe,narrator.
CHAPTERS: eight `{id:0..7,title,region,subtitle,palette:{ground,path,water,accent},weather:'clear'|'rain'|'fog'|'cold',intro:[line],outro:[line],nodes:[node x6],decorSeed}`. World 2200×1600. Spawn/camp at (220,1300). Use node coordinates [(440,1100),(800,850),(1350,1150),(1740,800),(1450,400),(1900,270)]. Paths open; decorative trees do not obstruct. No timed locks.
node: `{id,title,x,y,type:'talk'|'investigate'|'puzzle'|'battle'|'defend'|'boss',description,lines:[line],after:[line],choices?:[{id,label,result:[line],effect:{bond?:number,trust?:number,flag?:string}}],puzzle?:{kind:'sequence'|'rotate'|'deduce',clue,labels:[string],solution:[number]},enemies?:[enemyType],waves?:number,reward?:{xp,items:{itemId:count}}}`. Unique IDs. `line={speaker,text,id,voice?}` unique line IDs; no claim voice files exist until generated. Every chapter has >=2 combat objectives, distinct puzzle and a consequential choice; final node boss or talk. All main story nodes sequential. Choice consequences via flags; append responsive prose in UI for known flags if useful.
SIDEQUESTS: twelve `{id,title,chapter:0..7,summary,nodes:[node x3]}`. Stage nodes use coordinates e.g. (650,1380),(1050,550),(1800,1330). Core spawns optional stage enemies only when objective explicitly activated. Main and side battles may not overlap. Story owner can choose regions but avoid overlapping current main node <110 distance.
ITEMS maps wood,herb,grain,mushroom,ore,seed,stew,tea,roast,trap → `{name,icon}`.
WEAPONS maps sword/spear/axe → `{name,description,range,arc,damage,speed,stamina}`; `speed` total action duration seconds, `arc` half-angle radians. Sword 72/1.3/24/.46/12, spear 115/.45/29/.65/15, axe 77/1.6/44/.9/24.
RECIPES maps stew/tea/roast/trap → `{name,cost:{...},description}`. BUILDINGS maps kitchen/workshop/house/garden → `{name,cost:{...},description}`.

## Core: src/journey-core.js → MosslightJourney

Export `{Campaign, W:2200,H:1600}`. Data from global or require. Standalone, do not alter core.js. Agent owns meaningful tests tests/journey.test.cjs.
Campaign public state: `player` (x,y,hp,maxHp,mp,maxMp,stamina,maxStamina,level,xp,weapon,angle,moving,walk,action,dashTime,invulnerable,potions,coins), `chapter` current region, `unlocked` highest region index, `progress` array of 8 main node indexes, `sideProgress` object id→index, `completed` Set node IDs, `choices` object nodeId→choiceId, `flags` Set strings, `inventory` map, `buildings` Set, `garden` array plot records, `enemies` array, `projectiles`, `effects`, `traps`, `resources`, `events`, `elapsed`, `dead`, `finished`, `bond`, `trust`, `skillPoints`, `talents` {blade,fire,heart}, `weather`, `combat` null or {nodeId,wave,total}, `spell` fire/frost/lightning, `companion` {x,y,walk,moving}.
Enemies use types wolf/spitter/shell/burrow/wisp/boss, fields id,type,x,y,hp,maxHp,r,windup,attackX,attackY,alive,flash,phase,angle; `name` optional. Render telegraphs. Resources fields id,x,y,kind,amount,harvested.
Methods: `step(dt,input)`, `attack()`, `cast()`, `dash(dx,dy)`, `block(active)` (hold), `cycleWeapon()`, `cycleSpell()`, `useItem(id)`, `placeTrap()`, `resonance()`, `interact()` returns `{kind:'node',node}` or `{kind:'camp'}` or `{kind:'resource',...}` or null, `activeNode()` returns current main node, `visibleNodes()` returns main current/completed and side current nodes for current chapter, `beginNode(id)` returns boolean (starts objective battle if necessary), `resolveNode(id,{choice,answer}={})` returns `{ok,message}` and awards once. Reject unresolved battles, wrong puzzles, wrong order. `travel(index)` unlocked only and out of combat; preserve region kills/resources; `craft(id)`, `build(id)`, `plant(index)`, `harvest(index)`, `rest()`, `learnTalent(id)`, `revive()`, `serialize()`, static `fromSave(data)` (return null invalid); `xpNeeded` getter.
Events array `{type:'toast',text}`, `{type:'sound',name}`, `{type:'save'}`, `{type:'death'}`, `{type:'battleCleared',nodeId}`, `{type:'levelup'}`, `{type:'chapterComplete',chapter}`, `{type:'win'}`, `{type:'burst',x,y,color,count}`, `{type:'float',x,y,text,color}`. Core does not auto-resolve narrative on battle clear: UI presents after-dialogue then resolve. `resolveNode` returns status. Reward once. Travel only after current chapter finished unlocks next. `finished` at final objective. Scene UI pauses step while dialogs open. Inputs up/down/left/right/attack/magic/block. No forced waits to advance main story. Add summary `stats` with battles/parries/crafted/deaths useful.

## Renderer: src/journey-render.js → MosslightJourneyRenderer

Export class `Renderer`, constructor `(canvas)`, method `draw(game,{time,scene:null|{node,speaker,pose},map:false,reduced:false})`; returns camera if useful, expose `worldToScreen(x,y)` for UI markers optional. Canvas auto-resize. Full world maps, unique themed palettes/decor/structures per chapter, main nodes and resources, combat telegraphs, particles/effects, 3 weapon silhouettes through adapter to MosslightActors if possible. Use existing actor and portrait modules, do not edit them unless coordinated. Scene framing draws two/three actors, pans focus, ambient motes. Existing core fake actors have `kind:'hero'`, etc. Handle missing state gracefully during title rendering.

## UI: parent owns journey.html, journey.css, src/journey-ui.js

Title, controls, HUD, scene/cinematic subtitles/portraits, camp cooking/build/garden UI, journal/quests/map/talents/inventory, pause/death/ending, localStorage key `mosslight-long-campaign-v1`. Main flow near node E→scene lines→choice or puzzle or battle start→battle cleared E→after lines→resolve. Optional side quests same pipeline. Map travel uses `travel`. Use local generated speech if available; otherwise label system speech explicitly. Parent will generate voices after data stable. Duration labeled development target not verified gameplay.
