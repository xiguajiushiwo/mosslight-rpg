# 苔灯之森：归途来信 · 游戏简报

## 目标与情绪

可离线运行的中文俯视角动作 RPG 短篇。用户希望亲情与爱情能真正进入故事，有清楚可见的角色动作、不同玩法、成长选择、动画演出和配音。结局遵循用户选择：温暖但有遗憾，最后留下希望。

## 故事

林舟离家三年，收到父亲林远的一句“灯坏了，能回来一趟吗”。回乡后，他沿着已故母亲沈宁的音乐盒、苏晚的河灯和旧塔星图，重新认识家人沉默背后的爱。苏晚拥有看海、开书店的愿望，不是只为主角等待的奖励。父亲承认自己未寄出母亲病中的信；父子终于把想念说出口。

灯塔的光不会让母亲复生。最终的希望来自仍在身边的人、共同的早餐、书店和远方。未来约定改变尾声文字，不改变故事的情感基调。

## 章节与玩法

1. 序章：返乡、家书，学习移动与交互。
2. 第一封信：旧花园的音乐盒顺序谜题，听见母亲的记忆。
3. 第二封信：重逢苏晚，护送河灯到木桥南端；兼顾道路、伙伴与河灯状态。
4. 第三封信：旧塔星镜方向谜题，共同点亮旧星图。
5. 终章前夜：回家、和解、选择未来约定，获得父亲的月辉剑。
6. 最后的夜路与尾声：荒根守卫战，点灯，接受遗憾并走向明天。

探索、解谜、同行、对话与战斗交替。剧情、探索和战斗均提供成长；升级给予天赋点，在剑心、流萤、守望三个方向分配。苏晚加入后提供同行共鸣，具备治疗和范围攻击效果。

## 已实现范围

- 一张森林地图：村庄、花园、河流木桥、旧塔、遗迹；地图、背包、药水、金币、宝箱与本地自动存档。
- 原创分肢体角色绘制：行走摆臂与迈步、三式连击的起手/命中/收招、施法蓄力、翻滚、受伤与剧情姿态。
- 五幅原创人物/旁白立绘；9 场游戏内演出，运镜、记忆色调、河灯/星光、字幕与回放。
- 38 句已生成的本地中文神经合成配音，完整音频约 3 分 55 秒，支持静音、手动/自动推进和跳过。
- 不同章节谜题、可重试的护送、伙伴跟随、三系各三级天赋、任务武器、Boss 与完整结局。
- 键盘及触控操作；独立故事篇存档，旧版存档和源代码备份保留。

参考 [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) 的简短 brief、[art-bible](https://github.com/Donchitos/Claude-Code-Game-Studios/blob/main/.claude/skills/art-bible/SKILL.md) 和 [team-audio](https://github.com/Donchitos/Claude-Code-Game-Studios/blob/main/.claude/skills/team-audio/SKILL.md) 工作流，完成美术与声音的专业分工、设计约束和验证记录。原生 Canvas 2D 实现，不依赖完整 Claude Code 工作室或游戏引擎。

## 完成标准与边界

标题至结局的核心模拟可走通，实际浏览器验证关键剧情界面、谜题、动作、语音状态、天赋、存档与结局。游戏内演出属于实时 2D 动画，不是预渲染电影。配音为神经合成语音，不声称真人表演品质。乐趣、剧情情感与配音听感继续由玩家实际体验评价。
